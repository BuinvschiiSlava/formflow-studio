FormFlow Studio — локальный визуальный редактор динамических форм. В одном интерфейсе
соединены палитра элементов, упорядоченный конструктор, инспектор свойств и живой
предпросмотр Angular Formly. Форму можно экспортировать в версионируемый JSON и затем
безопасно импортировать с полной проверкой структуры.

## Зачем нужен проект

Большие Formly-конфигурации трудно писать вручную, проверять и переиспользовать. FormFlow
Studio отделяет переносимую модель формы от UI-библиотеки и позволяет собрать типовой
бизнес-сценарий визуально, сохранив прозрачный JSON-результат.

## Возможности

- добавление, выбор, копирование, удаление и изменение порядка элементов;
- поля text, email, number, textarea, date, select, radio, checkbox и toggle;
- элементы разметки heading, divider и section;
- настройка ключа, подписи, описания, placeholder, значения по умолчанию и ширины;
- настройка вариантов выбора и правил валидации;
- декларативные условия `show` и `enable` относительно другого поля;
- живой предпросмотр через Angular Formly;
- английская и русская локали документа;
- импорт и экспорт JSON версии `1`;
- история undo/redo на 50 шагов и автоматические локальные черновики;
- четыре практических шаблона бизнес-форм;
- детерминированная генерация TypeScript-интерфейса результата;
- локальное хранение без отправки форм на сервер;
- клавиатурное управление и адаптивный интерфейс;
- hash routing для стабильной работы на GitHub Pages.

## Запуск

Понадобятся Node.js 24 и npm 11. Версия Node записана в [`.nvmrc`](.nvmrc), а проект
указывает npm 11.17.0 в `package.json`.

```bash
nvm use
npm ci
npm start
```

После запуска откройте <http://localhost:4200/>.

### Основные команды

```bash
# Запуск для разработки
npm start

# Production-сборка
npm run build

# Unit-тесты
npm test

# Unit-тесты с покрытием
npm run test:coverage

# Проверка ESLint
npm run lint

# Проверка форматирования
npm run format:check

# Установка браузера и запуск E2E
npx playwright install chromium
npm run e2e
```

## Как пользоваться

1. Укажите название и язык формы.
2. Добавьте поля и элементы разметки из палитры.
3. Выберите элемент на рабочей области и настройте его в инспекторе.
4. При необходимости добавьте валидацию или условие.
5. Проверьте форму в живом предпросмотре.
6. Экспортируйте JSON либо импортируйте сохранённый документ.

Импорт сначала проверяет документ целиком, а затем создаёт отдельный локальный черновик,
не перезаписывая открытую форму. При ошибке показываются проблемные пути и пояснения;
частично корректный файл не применяется.

## Формат JSON

Приложение использует собственную декларативную модель, а не исполняемую конфигурацию
Formly. Текущая версия схемы — `1`. Полный пример и правила совместимости находятся в
[документации схемы](docs/JSON_SCHEMA.md).

Импортируемый файл всегда считается недоверенными данными. Функции, строковые Formly
expressions и другие исполняемые значения запрещены, а HTML-подобные строки выводятся как
обычный текст.

## Архитектура и качество

Доменный документ не зависит от Formly. Операции store изменяют состояние, а отдельный
адаптер строит конфигурацию только для предпросмотра. Валидация и сериализация выполняются
на границе приложения.

- [Архитектура](docs/ARCHITECTURE.md)
- [Тестирование](docs/TESTING.md)
- [Публикация](docs/DEPLOYMENT.md)
- [Политика безопасности](SECURITY.md)

Каждый pull request проходит форматирование, lint, unit-тесты, production-сборку, E2E и
автоматические accessibility-проверки. Дополнительно вручную проверяются клавиатурное
управление, фокус, адаптивность и экранный диктор.

## Данные и приватность

Документы остаются в браузере. Файл создаётся только после явной команды экспорта.
Аккаунтов и серверного хранилища нет. Не используйте реальные секреты и чувствительные
данные в публичной демонстрации.
