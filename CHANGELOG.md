## [1.0.0] - 2026-10-19

### Added

- Initial Angular application and domain document model.
- Visual form-building workspace, property editing, and live Formly preview.
- Versioned JSON import and export with runtime validation.
- English and Russian documentation.
- Unit, browser, accessibility, and deployment automation.

### Security

- Imported documents are handled as declarative data and cannot execute arbitrary Formly
  expressions, JavaScript, or HTML.
